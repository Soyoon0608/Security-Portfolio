Routing 실습

1. 실습 목적

여러 라우터로 구성된 네트워크에서 서로 다른 네트워크 간 통신이 가능하도록 라우팅을 구성하고, 라우팅 테이블을 확인하는 과정을 실습했다.

GNS3 환경에서 라우터의 인터페이스에 IP 주소를 설정하고 Serial 인터페이스를 이용하여 라우터 간 네트워크를 연결하였다.

또한 정적 라우팅과 동적 라우팅의 개념을 학습하고 OSPF를 이용한 라우팅을 실습했다.

---

2. 학습 내용

* 라우터 인터페이스 IP 설정
* Serial 인터페이스 설정
* 라우터 간 WAN 연결
* 정적 라우팅
* 동적 라우팅
* OSPF
* PPP / HDLC
* Routing Table 확인
* Ping을 이용한 통신 확인

---

3. 실습 환경

* GNS3
* Cisco Router
* Serial Interface
* PC

---

4. 네트워크 구성

라우터 여러 대를 Serial 인터페이스로 연결하여 서로 다른 네트워크 간 통신이 가능하도록 구성하였다.

라우터의 Ethernet 인터페이스는 LAN 영역에 연결하고, Serial 인터페이스는 라우터 간 WAN 영역 연결에 사용하였다.

---

5. 라우터 인터페이스 설정

각 라우터의 인터페이스에 IP 주소를 설정하고 활성화하였다.

```cisco
enable
configure terminal

interface serial 1/1
ip address 192.168.23.1 255.255.255.0
no shutdown
exit
```

라우터의 각 인터페이스에 서로 다른 네트워크 대역을 설정하여 라우터 간 통신 경로를 구성하였다.

---

6. PPP 설정

라우터 간 Serial 연결에서 PPP를 사용하는 경우 인터페이스의 캡슐화를 PPP로 설정하였다.

```cisco
interface serial 1/1
encapsulation ppp
no neighbor-route
```

실습에서는 R1-R2 구간에서 PPP를 사용하였으며, HDLC를 사용하는 구성과 비교하였다.

---

7. OSPF 설정

라우터 간 네트워크 정보를 자동으로 교환하기 위해 OSPF를 구성하였다.

```cisco
router ospf 100
router-id 2.2.2.2
```

인터페이스에서는 OSPF cost를 설정하였다.

```cisco
interface serial 1/2
ip ospf cost 10
```

라우터별로 서로 다른 Router ID를 지정하여 OSPF 라우팅 영역을 구성하였다.

예시:

```text
R2 → 2.2.2.2
R3 → 3.3.3.3
```

---

8. 라우팅 테이블 확인

라우팅이 정상적으로 구성되었는지 확인하기 위해 다음 명령어를 사용하였다.

```cisco
show ip route
```

라우팅 테이블에서는 라우팅 방식에 따라 다음과 같이 표시된다.

```text
C - Connected
S - Static
R - RIP
O - OSPF
```

OSPF를 통해 학습한 경로는 `O`로 표시되는 것을 확인할 수 있다.

---

9. 통신 확인

라우팅 설정 후 서로 다른 네트워크에 위치한 장비 간 Ping을 수행하여 통신 가능 여부를 확인하였다.

```cisco
ping [목적지 IP]
```

Ping 응답을 통해 라우터 간 경로가 정상적으로 형성되었는지 확인하였다.

---

10. 실습 결과

라우터의 인터페이스에 IP 주소를 설정하고 Serial 연결을 구성하였다.

이후 OSPF를 적용하여 라우터 간 네트워크 정보를 교환하고, `show ip route` 명령어를 통해 학습된 경로를 확인하였다.

이를 통해 라우터가 목적지 네트워크까지의 경로를 라우팅 테이블에 저장하고 이를 기반으로 패킷을 전달하는 과정을 확인하였다.

---

11. 배운 점

이번 실습을 통해 스위치가 동일한 LAN 내부의 프레임 전달을 담당하는 것과 달리, 라우터는 서로 다른 네트워크 사이에서 패킷이 이동할 수 있도록 경로를 결정한다는 것을 이해하였다.

특히 `show ip route`를 통해 라우팅 테이블을 직접 확인하면서 Connected, Static, OSPF와 같은 경로가 어떻게 구분되는지 확인할 수 있었다.

또한 Serial 인터페이스의 PPP 및 HDLC 설정을 실습하면서 라우터 간 WAN 연결과 캡슐화 방식에 대해서도 학습하였다.
